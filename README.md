# Data Analytics Dashboard Portfolio

A collection of data analytics and business intelligence dashboards built using Power BI, SQL, and Python. This repository showcases end-to-end analytics work — from raw data cleaning and transformation to interactive dashboard design.

## 📁 Projects

| Project | Description | Tools |
|---|---|---|
| **Finance Dashboard** | Financial performance tracking and KPI visualization for customer-facing reporting | Excel |
| **HR Analytics Dashboard** | Workforce metrics including headcount, attrition, and employee performance insights | Power BI |
| **Weather Data Dashboard** | Interactive dashboard visualizing historical and real-time weather trends | Power BI(Weather API) |
| **Customer Trends Data Analysis** | Customer behavior and sales trend analysis using SQL and Python | SQL, Python, Power BI |
| **Sales Dashboard** | Sales performance tracking across regions/products | Power BI (.pbix) |

## 🛠️ Tools & Technologies

- **Power BI** — dashboard design, DAX measures, data modeling
- **SQL** — data extraction, querying, and transformation
- **Python** — data cleaning, analysis, and automation
